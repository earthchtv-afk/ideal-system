# Student Assignment Management System

ระบบจัดการการส่งงานนักเรียนออนไลน์

## รายละเอียดโครงงาน

ระบบช่วยให้ครูสามารถสร้างและจัดการงานที่มอบหมาย
และให้นักเรียนสามารถดูรายละเอียดงาน ส่งงาน
และตรวจสอบสถานะการส่งงานได้

## Features

- สมัครสมาชิก
- Login / Logout
- นักเรียนดูรายการงาน
- นักเรียนดูรายละเอียดงาน
- นักเรียนส่งงาน
- ตรวจสอบสถานะการส่งงาน
- ครูสร้างงาน
- ครูแก้ไขงาน
- ครูลบงาน
- ครูตรวจงาน
- ครูให้คะแนน
